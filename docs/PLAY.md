# วิธีลองเล่น GETPOINT

## ★ แบบที่คุณต้องการตอนนี้ — เครื่องมืออ่านใบเสร็จ → Excel (ไม่ต้องมี LINE/loga)

เข้าเว็บ → อัปโหลด/ถ่ายใบเสร็จ → **OCR จริงอ่าน** → ดูผล + **โหลด Excel** · เอารูปมาป้อนฝึกได้เรื่อยๆ

```bash
cd backend
python -m uvicorn app.tools.ocr_tool_api:app --port 8100
```

เปิด **`http://localhost:8100`** แล้ว:
1. แตะ **"แตะเพื่อถ่าย หรือเลือกรูป"** → เลือกใบเสร็จ (เลือกหลายใบพร้อมกันได้)
   - บนมือถือจะเปิดกล้องให้ **ถ่าย/สแกน** ได้เลย ไม่ใช่แค่แนบรูป
2. กด **"อ่านใบเสร็จ"** → รอ (ใบแรกโหลดโมเดล ~20 วิ ใบต่อไป ~6 วิ/ใบ)
3. เห็นตาราง: ยอดเงิน / ร้าน / วันที่ / เวลา / เลขอ้างอิง / รายการสินค้า / **ข้อความ OCR ดิบ**
4. กด **"⬇ ดาวน์โหลด Excel"** → ได้ไฟล์ `receipts_ocr.xlsx` (1 แถวต่อ 1 ใบ)

> เครื่องมือนี้ **ตัด LINE/loga/OTP/คิว/จำลอง ออกหมด** — เหลือแค่ รูป → OCR จริง → Excel
> เอาไว้ป้อนรูปฝึกจนพอใจ · พอพร้อมค่อยไปต่อเรื่อง loga API

## แบบ A — เล่น UX ในเบราว์เซอร์ (จำลอง — ไว้ดูหน้าจอลูกค้าเฉยๆ)

> นี่คือ LIFF app ของลูกค้า (สาย LINE) ที่ยังทำต่อทีหลัง — **จำลอง** ผลสแกน
> ไม่ใช่ OCR จริง · ถ้าอยากได้ OCR จริง+Excel ใช้เครื่องมือด้านบนสุด

เห็น "หน้าจอที่ลูกค้าเห็น" ครบทั้ง flow — จำลองทุกอย่างในเบราว์เซอร์

```bash
cd frontend
npm install     # ครั้งแรกครั้งเดียว
npm run dev
```

เปิด `http://localhost:5173` แล้วเดินตามนี้:

1. **หน้าสมัคร** — กรอกเบอร์อะไรก็ได้ (เช่น `0812345678`) → กด "ขอรหัส OTP"
2. **หน้า OTP** — กรอก **`123456`** (รหัสพรีวิวที่ตั้งไว้) → กด "ยืนยัน"
3. **ยืนยันสำเร็จ** — เห็นรหัสสมาชิก → กด "เริ่มสแกนใบเสร็จ"
4. **หน้าสแกน** — แตะเพื่อถ่าย/เลือกรูป → ระบบจำลองว่า "กำลังอ่าน..." → แจ้งแต้ม

> ⚠ แบบ A **ไม่ได้อ่าน OCR จริง** — จำลองผลว่าสำเร็จ เพื่อให้เห็น flow หน้าจอ
> อยากเห็น "สมองจริง" อ่านใบเสร็จ → ดูแบบ B

## แบบ B — ดูสมองจริงทำงานกับใบเสร็จจริง 28 ใบ

ไม่ต้องมี LINE/loga/Redis — รันเครื่องมือวัดที่ยิงใบเสร็จจริงผ่านระบบจริง

```bash
cd backend
$env:PYTHONUTF8=1                          # PowerShell (กันภาษาไทยเพี้ยน)
python -m app.tools.measure_ocr            # อ่านยอดเงิน (ครั้งแรกโหลดโมเดล ~20 วิ)
python -m app.tools.measure_fields         # ทุก field: ยอด/วันที่/เวลา/ร้าน/เลขอ้างอิง
python -m app.tools.measure_duplicate      # กันใบซ้ำ (จับได้/หลุด/จับเกิน)
python -m app.tools.measure_items          # รายการสินค้า + ราคา
python -m app.tools.try_ocr ../tests/fixtures/receipts/LINE_ALBUM_Receip_260819_1.jpg
```

`try_ocr` ป้อนไฟล์เดียว จะเห็นว่าระบบอ่านอะไรออกมาบ้างทีละบรรทัด + สรุปยอด/ร้าน/วันที่

> ครั้งแรกช้าเพราะโหลดโมเดล PaddleOCR · ครั้งต่อไปเร็ว (แคชบรรทัด OCR ไว้)
> แก้โค้ด OCR/image_prep แล้วต้องเติม `--fresh` ให้อ่านรูปใหม่

## แบบ C — รันทั้งระบบจริง (web + worker + DB + Redis)

ต้องมี Docker · ใช้ของปลอมสำหรับ loga/SMS/LINE (ยังไม่ต้องมี credential)

```bash
docker-compose up          # ยก Postgres + Redis + web + worker
```

แล้วยิง API ตรงๆ (ยังไม่มี LINE token จริง จะติดที่ auth — เหมาะกับดู endpoint เฉยๆ):

```bash
curl http://localhost:8000/health
```

หน้า admin (ต้องตั้ง `ADMIN_TOKEN` ใน `.env` ก่อน):

```bash
curl -H "Authorization: Bearer <ADMIN_TOKEN>" http://localhost:8000/admin/metrics
```
